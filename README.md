# Ecommerce de periféricos y hardware para PC

Proyecto práctico de desarrollo web de la **Comisión 28 de RollingCode School**. Somos el **Equipo 5** y nuestro desafío es diseñar y construir un sitio de comercio electrónico dedicado a la venta de periféricos y componentes de hardware para computadoras.

## Objetivo

Aplicar los conocimientos de desarrollo frontend creando una tienda web clara, atractiva y adaptable a distintos dispositivos. El proyecto forma parte de nuestro proceso de aprendizaje y se construye de manera colaborativa.

## Tecnologías

- HTML5
- CSS3
- Bootstrap 5

## Cómo ver el proyecto

1. Cloná o descargá este repositorio.
2. Abrí `index.html` en tu navegador.

El proyecto no requiere instalación de dependencias ni un proceso de compilación para esta etapa inicial.
